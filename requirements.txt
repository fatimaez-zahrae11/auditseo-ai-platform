Project Requirements

Docker setup requirements:

- Docker Desktop
- Docker Compose
- Git

Manual setup requirements:

- PHP 8.2+
- Composer
- Node.js / npm
- PostgreSQL
- Redis
- Git

Dependency files:

- Backend dependencies: backend/composer.json and backend/composer.lock
- Frontend dependencies: frontend/package.json and frontend/package-lock.json
- Docker installs dependencies automatically inside containers
