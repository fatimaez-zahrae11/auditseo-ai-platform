Project Requirements

Recommended Docker setup:

- Docker Desktop
- Docker Compose
- Git

Manual setup without Docker:

- PHP 8.2+
- Composer
- Node.js / npm
- PostgreSQL
- Redis
- Git

Dependency files:

- Backend dependencies are installed from backend/composer.json and backend/composer.lock.
- Frontend dependencies are installed from frontend/package.json and frontend/package-lock.json.
- Docker installs these dependencies automatically inside containers.
