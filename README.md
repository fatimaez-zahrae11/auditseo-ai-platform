# AuditSEO - Secure AI-Powered SEO Audit Platform

A secure AI-powered web platform for automated SEO audits, technical analysis, smart recommendations, and audit history tracking.

## Docker development

The full Laravel, React, PostgreSQL, Redis, queue, and scheduler stack can run with Docker Compose. See [docs/docker.md](docs/docker.md) for setup, operations, testing, and production guidance.
